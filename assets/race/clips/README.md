# Race clips

One short video per race segment, played after **Start race** and after each aid station
(owner request, 3 November 2026). Segment 1 runs from the start to aid station 1; the last segment
ends at the finish line. A missing clip is skipped (the game goes straight to the aid station).

    assets/race/clips/RACE-001/segment-1.mp4   start → aid station 1
    assets/race/clips/RACE-001/segment-2.mp4   aid station 1 → finish (Forest First Steps has 2 segments)

Segments per race: RACE-001…004: 2 · RACE-005, 006: 3 · RACE-007: 4 · RACE-008: 5 · RACE-009: 6 ·
RACE-010: 7 · RACE-013: 7 · RACE-011, 012, 014…017: 8 (a race's segments follow its distance and climb).

Clips so far: RACE-001 segments 1 and 2 (owner videos of 7 November 2026, exported at 720p from
InShot, converted to 720 × 1280 with their sound, 4.3 and 2.5 MB) and RACE-002 segment 1 (6 November
2026, 720 × 1280 with sound, 3.0 MB).

**Upload tips:** export at 720p (InShot or CapCut) so the file stays under GitHub's 25 MB upload
limit; WhatsApp shrinks videos to 480p. Upload the file already named `segment-1.mp4` (rename it on your computer first).
Renaming a video on the GitHub website can leave an empty file (it happened with RACE-001: two
bytes instead of the video). The checks now fail when a clip is not a real video.

- **Format:** MP4 (H.264). A `.webm` with the same name is used first when present.
- **Picture:** vertical 9:16, 720 × 1280 (at most 1080 × 1920).
- **Length:** 4–8 seconds (longer clips can be skipped). **Sound:** ambient sound is kept (owner
  decision, 7 November 2026); the player starts it when the browser allows, otherwise it plays muted
  and the sound button turns it on. AAC, 96 kbps.
- **Size:** aim for 3 MB or less per clip.
- **Poster (optional):** `segment-1.jpg` or `.webp`, shown while the video loads.

The player can skip a clip; with "reduce motion" on, clips are skipped. A clip that has not started
after 5 seconds is skipped too. Clips are only pictures: the segment is already run by the server.
